## Code of Conduct

Be direct, be kind, assume good faith. Specifically:

- Critique code and ideas, not people.
- Disagreement is fine; disrespect isn't. No personal attacks, harassment, or
  discriminatory language.
- Keep discussion on-topic - issues and PRs are for the project, not for
  unrelated grievances.
- Maintainers make the final call on what gets merged. A "no" isn't personal.

Reports of unacceptable behavior can be opened as a GitHub issue, or emailed
to the maintainer listed on the [GitHub profile](https://github.com/abubakarsiddik31)
if you'd rather not post publicly.
