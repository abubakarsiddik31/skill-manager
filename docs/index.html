Features

Unified view

See every tool's skills directory in one dashboard instead of digging through ~/.claude, ~/.codex, and friends.

Enable / disable

Toggle a skill off without deleting it — fully reversible, never touches the tool's own config.

Edit & delete

Open a skill's SKILL.md and edit it directly, or remove it entirely when it's no longer needed.

Per-project breakdown

Track individual project folders and see exactly which skills are installed inside each one.
